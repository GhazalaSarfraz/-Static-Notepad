
# Static Notepad App

A simple *Flutter Notepad Application* that allows users to create, view, update, and delete notes. Notes are stored locally using the *SQFlite* package. This app is perfect for understanding how local databases work with Flutter.

---

## Features

- Add new notes with title, age, description, and email
- Display list of all notes
- Tap to update any note
- Swipe to delete a note
- Data is saved locally using SQLite (no internet required)

---

## Technologies Used

- *Flutter* & *Dart*
- *SQFlite* – Local database
- *Path Provider* – To get storage directory
- *Material UI* – For clean and responsive design

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android/iOS Emulator or Physical Device

### Installation Steps

```bash
# Clone the repository
git clone https://github.com/GhazalaSarfraz/-Static-Notepad.git

# Navigate into the project directory
cd -Static-Notepad

# Get all the dependencies
flutter pub get

# Run the app
flutter run
